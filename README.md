# Prescriptive Analytics & Optimization Portfolio

A collection of deterministic decision models translating business problems into decision variables, objective functions, constraints, optimal solutions, sensitivity analysis, and managerial recommendations.

## Methods
- Linear Programming
- Integer Programming
- Binary Optimization
- Nonlinear Optimization
- Transportation / Network Flow
- Assignment
- Facility Location
- Set Covering
- Workforce Planning
- Blending
- Capacity / Resource Allocation
- Pricing
- Multi-period planning

## Tooling
Excel Solver • OpenSolver • SolverTable • Python • Gurobi / gurobipy

## Modeling discipline
**Business question → decision variables → objective → constraints → domains → solve → validate → sensitivity/scenario analysis → recommendation**

## Representative portfolio cases
- EV charging hub / facility-location coverage
- workforce staffing
- transportation and distribution
- blending/resource allocation
- nonlinear pricing
- fleet/capacity planning

## Known submitted-course results retained as evidence
- Eco Rentals fleet: minimum cost approximately $640K
- RPC staffing: 10 full-time + 13 part-time, cost $2,911
- 10-city EV hub model: Portland, Salt Lake City, Tucson and Los Angeles selected in one formulation
- ≤200-mile coverage extension: 7 hubs
- TexCorp pricing example: Px=10, Py=15, revenue $57,500
- Factory-layout example: total distance 200

These are course-solution results; the public repository should include only models that can be reconstructed and validated from source files.
